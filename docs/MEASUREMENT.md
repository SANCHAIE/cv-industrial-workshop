# วัดขนาดวัตถุจากภาพอย่างละเอียด (คู่มือย่อ)

ลองจริงได้ใน `notebooks/11_measurement.ipynb` (ภาพจำลองที่รู้ขนาดจริง เทียบทุกวิธีได้)

## หลักการ
ขนาดจริง (มม.) = จำนวนพิกเซล ÷ px/mm  ค่า px/mm มาจากการ**สอบเทียบ**ด้วยวัตถุที่รู้ขนาด  ความแม่นที่ทำได้จริงราว **1/10 ของขนาดพิกเซล** เมื่อติดตั้งถูก และไม่ดีกว่า **1 พิกเซล** ถ้าไม่ทำอะไรเลย

## แหล่งความคลาดเคลื่อน 5 อย่าง และวิธีแก้
| แหล่ง | ขนาดโดยทั่วไป | แก้ด้วย |
|---|---|---|
| ความละเอียดพิกเซล | ±0.5 px | กล้องละเอียดขึ้น ซูมให้ชิ้นงานเต็มภาพ Sub-pixel |
| วัตถุสูงไม่เท่าวัตถุสอบเทียบ (Parallax) | 1–5% | วางระนาบเดียวกัน หรือเลนส์ Telecentric |
| กล้องเอียง (Perspective) | 1–10% ต่างกันคนละฝั่งภาพ | ตั้งฉาก หรือจุดอ้างอิง 4 จุด + Homography |
| เลนส์บิดเบี้ยว (Distortion) | 0.5–3% ที่ขอบภาพ | cv2.calibrateCamera ด้วยลายหมากรุก |
| ขอบไม่คม (เบลอ แสง เงา) | 1–3 px | Backlight โฟกัสคม วัดขอบที่ 50% |

## 4 วิธี จากง่ายไปแม่น
| วิธี | ความแม่นที่ได้ (ทดลองในชุดนี้) | เมื่อไรใช้ |
|---|---|---|
| **1. วัตถุอ้างอิง + Threshold + minAreaRect** | ผิดราว 1–2 px | ทดลอง งานที่ Tolerance หลวม (±0.5 มม.) |
| **2. จุดอ้างอิง 4 จุด + Homography** | แก้กล้องเอียงจากผิด 5 มม. เหลือ 0.1 มม. | กล้องตั้งฉากไม่ได้ วัตถุแบน |
| **3. Sub-pixel edge (ขอบที่ 50% ของความสว่าง + เฉลี่ยหลายเส้น)** | ผิดราว 0.3 px และ**ไม่แย่ลงเมื่อภาพเบลอ** | ต้องการ ±0.05 มม. |
| **4. เลนส์ Telecentric + Backlight** | ไม่ขึ้นกับระยะและความสูงของวัตถุ | ±0.01 มม. หรือวัตถุสูง |

## ขั้นตอนติดตั้งและสอบเทียบ
1. กล้องตั้งฉากกับระนาบชิ้นงาน (ใช้ระดับน้ำ) หรือติดจุดอ้างอิง 4 จุดบนจิ๊ก
2. **Backlight** ให้ได้เงาดำขอบคม  ไม่ได้ใช้ไฟโดม
3. โฟกัสที่ขอบชิ้นงาน  รูรับแสง f/4–f/8
4. วัตถุสอบเทียบอยู่**ระนาบเดียวกัน**และขนาดใกล้เคียงชิ้นงาน (งานจริงใช้ Gauge block / Calibration target)
5. สอบเทียบ 2 ขนาด × 3 ตำแหน่งในภาพ  ถ้าต่างกัน > 0.5% ต้องแก้ Distortion
6. ทดสอบ **Repeatability 30 ครั้ง**: รายงานค่าเฉลี่ย ± 3σ  ใช้คัดได้เมื่อ 3σ < 10–30% ของช่วง Tolerance (Gauge R&R)
7. สอบเทียบซ้ำทุกกะ หรือทุกครั้งที่ขยับกล้อง

## สูตรเลือกกล้อง
ขนาดพิกเซล (มม.) = FOV (มม.) ÷ จำนวนพิกเซลด้านนั้น  ต้องการความแม่น X มม. → ขนาดพิกเซลควรเล็กกว่า **X/3** (Threshold) หรือ **X** (Sub-pixel)
ตัวอย่าง: ชิ้นงาน 100 มม. กล้อง 2448 px → 0.041 มม./px  ได้ความแม่นราว ±0.12 มม. (Threshold) หรือ ±0.04 มม. (Sub-pixel)

## ฟังก์ชัน OpenCV ที่ใช้
`cv2.minAreaRect` (กว้าง × ยาว + มุม), `cv2.minEnclosingCircle` / `cv2.fitEllipse` (เส้นผ่านศูนย์กลาง), `cv2.fitLine` (ขอบตรงจากหลายจุด), `cv2.cornerSubPix` (มุมละเอียดกว่าพิกเซล), `cv2.getPerspectiveTransform` + `cv2.warpPerspective` (แก้กล้องเอียง), `cv2.calibrateCamera` + `cv2.undistort` (แก้เลนส์บิดเบี้ยว), `cv2.arcLength` (เส้นรอบรูป)

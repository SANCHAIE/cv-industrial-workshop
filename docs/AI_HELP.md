1. **บอกไฟล์และตำแหน่ง** เช่น “notebook 06 ข้อ 1 ฟังก์ชัน compare_to_reference”  หรือคัดลอกโค้ดส่วนนั้นไปวาง
2. **บอกสิ่งที่เห็น และสิ่งที่ต้องการ** เช่น “ได้ NG ทุกรูป แต่ชิ้นงานดีควรเป็น OK”  ถ้ามี error ให้คัดลอกข้อความ error ทั้งหมดไปด้วย
3. **ขอให้อธิบายทีละบรรทัด** จะได้เข้าใจและแก้ต่อเองได้ ไม่ใช่แค่คัดลอก

- **เริ่มเล็ก** แก้ทีละอย่าง รันทดสอบทุกครั้ง ดีกว่าขอให้ AI เขียนทั้งระบบในครั้งเดียว

## ใช้ LLM สั่งการกล้อง Basler

ใช้ได้ 2 แบบ
- **AI สั่งกล้องเอง:** AI ที่รันคำสั่งบนเครื่องได้ เช่น Claude Code หรือ Claude Desktop ที่เปิดสิทธิ์ควบคุมเครื่อง  AI เขียนโค้ด รันกับกล้องจริง และรายงานผลเอง
- **AI เขียนโค้ดให้:** ChatGPT, Claude, Gemini ในเบราว์เซอร์  คัดลอกโค้ดไปรันใน notebook เอง

### Prompt ตั้งต้น (ส่งครั้งแรกครั้งเดียว)
```
คุณเป็นผู้ช่วยควบคุมกล้องอุตสาหกรรมบนเครื่องนี้
- กล้อง: Basler acA2440-20gc (GigE, 5 MP, สี) ต่ออยู่กับเครื่อง ใช้ไลบรารี pypylon
- โค้ดอยู่ที่โฟลเดอร์ ~/cv-industrial-workshop
- ใช้ฟังก์ชันจาก scripts/vision_camera.py:
  grab_one('basler', exposure_us=..., gain=...)  ถ่าย 1 ภาพแล้วปิดกล้อง คืนภาพ BGR (OpenCV)
  BaslerSource(emulate=False, exposure_us=...)   เปิดกล้องค้างไว้ ใช้ .read() ถ่ายต่อเนื่อง และ .close()
กติกา:
1. ปิดกล้องทุกครั้งหลังใช้ ถ้าเปิดไม่ได้ให้บอกว่าอาจมี pylon Viewer หรือ web app เปิดกล้องอยู่
2. ห้ามเปลี่ยนค่าเครือข่ายหรือ IP ของกล้อง
3. ทุกครั้งที่ถ่าย รายงาน: ขนาดภาพ ความสว่างเฉลี่ย (0-255) และบันทึกภาพไว้ที่ ~/cv-industrial-workshop/captures/
4. อธิบายสั้นๆ ว่าทำอะไรไป และค่าที่ใช้คืออะไร
```

### คำสั่งตัวอย่าง
| ระดับ | คำสั่ง |
|---|---|
| ง่าย | ถ่ายภาพ 1 ภาพ ด้วย Exposure 50 มิลลิวินาที แล้วบอกความสว่างเฉลี่ย |
| ง่าย | หาค่า Exposure ที่ทำให้ภาพสว่างเฉลี่ยราว 120 โดยลองทีละขั้น ไม่เกิน 6 ครั้ง แล้วบอกค่าที่ได้ |
| ง่าย | ถ่ายภาพที่ Exposure 10, 50 และ 100 มิลลิวินาที แล้วรวมเป็นภาพเดียวเรียงซ้ายไปขวา |
| กลาง | ตรวจว่ากล้องต่อด้วยความเร็วสายเท่าไร (GevLinkSpeed) และถ่ายได้กี่ภาพต่อวินาที ถ้าต่ำกว่า 1000 Mbps ให้บอกสาเหตุที่เป็นไปได้ |
| กลาง | ถ่ายภาพ แล้วนับวัตถุสีน้ำเงิน (H 95–125) ที่ใหญ่กว่า 5000 พิกเซล วาดกรอบ แล้วบันทึกภาพผลลัพธ์ |

| ยาก | ถ่ายภาพทุก 2 วินาที 10 ภาพ นับวัตถุสีน้ำเงิน บันทึกผลเป็น CSV (เวลา, จำนวน, ความสว่าง) แล้วสรุป |
| ยาก | ตั้ง AOI ให้เหลือครึ่งกลางของภาพ วัดว่าถ่ายเร็วขึ้นกี่ภาพต่อวินาที แล้วคืนค่า AOI เดิม |

### ผลจริง (ทดสอบกับกล้อง acA2440-20gc ตอนเตรียมอบรม)

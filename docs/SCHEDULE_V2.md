## แบบสำรวจก่อนอบรม (3 ข้อ)
1. **เคยเขียนโปรแกรมไหม**  ไม่เคยเลย / เคยบ้าง (Excel macro, Arduino, PLC) / เขียน Python ได้
2. **เครื่องที่จะนำมา**  Windows / Mac / ไม่มี ขอใช้เครื่องแล็บ
3. **ติดตั้งโปรแกรมบนเครื่องนั้นได้เองไหม**  ได้ / ต้องให้ IT บริษัททำ / ไม่แน่ใจ

ข้อ 1 ใช้แบ่งเส้นทาง (ไม่เคย → A, เขียน Python ได้ → B, เคยบ้าง → เลือกเอง)  ข้อ 2–3 ใช้เตรียมเครื่องแล็บและนัดคลินิก

## สิ่งที่ TA ต้องเตรียม
- เครื่องแล็บติดตั้งครบ (รัน start_*.* แล้วตรวจผ่าน 11/11) อย่างน้อย 1 เครื่องต่อ 4 คน สำหรับคนที่เครื่องไม่พร้อม
- web app ของอาจารย์เปิดในวง LAN (`--server.address 0.0.0.0`) ให้คนที่เครื่องยังไม่พร้อมใช้ชั่วคราว
- กล้อง Basler ตั้งภาพใน pylon Viewer ให้ดีตั้งแต่เช้า (รูรับแสง โฟกัส White Balance) และเช็กว่าสายเป็น Gigabit
